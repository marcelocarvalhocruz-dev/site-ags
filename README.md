# Site AGS

Versão estática para GitHub Pages.

Em Settings > Pages, selecione Deploy from a branch, branch main, pasta / (root).

O site é público. O editor SiteFácil, painel administrativo, banco de dados e recebimento de formulários exigem hospedagem de servidor e não fazem parte desta versão. Links diretos de e-mail e WhatsApp continuam disponíveis quando configurados.
